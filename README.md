# 💰 FinAI

FinAI is an Android-based personal finance management application that helps users track their income and expenses, monitor spending habits, and gain meaningful financial insights through an interactive dashboard.

One of the application's key features is its ability to analyze transaction SMS messages from banks and digital payment platforms, automatically recording expenses and organizing them into categories. This reduces manual effort and gives users a clear overview of their financial activities.

---

## 📱 Features

* 📩 Automatic expense tracking from transaction SMS messages
* 🏦 Supports transaction alerts from banks
* 💳 Supports payment apps such as Google Pay, PhonePe, and Paytm
* 🏷️ Smart expense categorization
* 📊 Interactive finance dashboard
* 📅 Monthly and yearly spending analysis
* 💰 Budget planning and monitoring
* 📝 Manual expense management
* 📜 Complete transaction history
* 📈 Spending trends and financial insights
* 🎨 Simple and user-friendly Android interface

## 🎯 Project Objective

The goal of FinAI is to simplify personal finance management by automatically capturing financial transactions from SMS messages and presenting them through a clean, informative, and easy-to-use dashboard.

---

## 🚀 Key Functionalities

### Transaction Tracking

* Reads transaction SMS messages
* Detects debit and credit transactions
* Extracts transaction amount, merchant name, date, and time
* Automatically stores transaction records

### Expense Management

* Automatic expense categorization
* Manual expense addition
* Daily, weekly, monthly, and yearly expense tracking
* Complete transaction history

### Analytics Dashboard

* Spending reports
* Category-wise expense analysis
* Budget monitoring
* Expense trends
* Financial summaries

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Thira26/FinAI.git
```

### 2. Open in Android Studio

Open Android Studio and select the cloned project.

### 3. Build the project

Allow Gradle to sync and download the required dependencies.

### 4. Run the application

Run the project on an Android emulator or a physical Android device.
